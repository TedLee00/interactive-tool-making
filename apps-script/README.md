# 선생님용 구글 시트 연결하기 (한 번만)

연결하면 모든 학생의 기기에서 생긴 기록이 **선생님 구글 시트 하나**에 모이고, 게임 속 명예의 전당도 **반 전체 순위**로 바뀌어요.

## 연결 방법

1. 구글 드라이브에서 **새 구글 시트**를 만들어요. (이름 예: 품사 원정대 기록)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 나오는 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣고 저장(💾)해요.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. **배포**를 누르고 권한을 허용하면 `https://script.google.com/macros/s/…/exec` 주소가 나와요.
   (권한 화면에서 "확인되지 않은 앱"이 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**)
6. 그 주소를 Claude에게 알려 주세요. (또는 `data/config.json`의 `"rankApi": ""` 따옴표 안에 넣기)

> 나중에 `Code.gs`를 바꿔 붙여 넣었다면 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** 를 해야 반영돼요. (주소는 그대로)

## 시트에 생기는 탭

| 탭 | 언제 한 줄씩 | 들어가는 내용 |
|---|---|---|
| **성적표** | 학생이 원정을 끝낼 때 | 이름 · 난이도 · 회차 · 정답/문항 · 정답률 · **유형 1~12별 정답률** · 약한 유형 · 코인 · 턴 · 총점 · 누적 점수 · 레벨 · 받은 과자 · 펫 수 · 아너스 미션 · 걸린 시간 · 미니게임별 최고 점수 |
| **퀴즈기록** | 퀴즈 칸(5문제)을 끝낼 때 | 이름 · 회차 · 지역 · 칸 · 유형 · 맞힌 수 · 정답률 · **틀린 문제(질문 → 내 답 / 정답)** — 끝까지 못 간 학생도 기록돼요 |
| **과자획득** | 미니게임에서 과자를 받을 때 | 이름 · 과자 · 받은 게임 · **쿠폰 번호** · 지급 확인(선생님이 체크) |
| **품사원정대_점수** | 미니게임 · 완주가 끝날 때 | 시각 · 게임 · 이름 · 점수 (명예의 전당 계산용 원본) |
| **명예의전당** | 점수가 기록될 때마다 자동 정리 | 게임별 🥇🥈🥉 1~10위 (학생마다 최고 점수) |

연습장(quiz-lab)에서 한 미니게임 점수도 명예의 전당에 들어가요. 성적표 · 퀴즈기록 · 과자획득은 **보드 게임(원정)** 에서만 기록돼요.
