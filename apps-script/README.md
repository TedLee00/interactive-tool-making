# 반 전체 순위표 연결하기 (선생님용, 한 번만)

지금은 순위표가 **기기마다 따로** 저장돼요. 아래를 한 번 해 두면 모든 학생의 휴대폰 점수가 **한 순위표**에 모여요.

1. 구글 드라이브에서 **새 구글 시트**를 만들어요. (이름 예: 품사 원정대 순위표)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 나오는 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣고 저장(💾)해요.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. **배포**를 누르고 권한을 허용하면 `https://script.google.com/macros/s/…/exec` 주소가 나와요.
6. 그 주소를 Claude에게 알려 주거나, `data/config.json`의 `"rankApi": ""` 따옴표 안에 넣어요.

점수는 시트의 `품사원정대_점수` 탭에 한 줄씩 쌓여요 (시각 · 게임 · 이름 · 점수). 순위는 학생마다 그 게임의 **최고 점수** 기준이고, 누적 점수와 판 수도 함께 보여 줘요.
