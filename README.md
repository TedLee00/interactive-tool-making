# 품사 원정대 (Chunk Quest)
「영어의 이해」 특강 내용으로 만드는 1인용 3D 보드게임. 기획서: `GAME_SPEC.md`

## 미니게임 · 연출 (4·5단계 일부 앞당김)
- `src/games/` — 청크런 · 청크 크레인 · 청크 카트 · 청크 사격장 (Canvas 2D 공통 엔진)
- `src/fx/` — 기존 앱 효과 엔진 이식(BGM 합성 · 댄스 쇼 · "마!" · 과자 그림) + 콜아웃(이지/야르/레전드)
- `data/minigames.json` — 미니게임 학습 단어·미션
- `public/assets/kart/`, `public/assets/snacks/` — 카트·과자 그림 (기존 앱)

## 3단계: 3D 보드·캐릭터·주사위
- `index.html` — 게임 (타이틀 → 등록 → 캐릭터 선택 → 3D 보드)
- `data/board.json` — 40칸 여정 (지역 4곳, 칸 종류·유형)
- `data/characters.json` — 플레이어 캐릭터 8명 + 안내 Ted 선생님 (이름·성격·대사)
- `public/assets/characters/*.svg` — 캐릭터 그림 (기존 앱 캐릭터. 같은 이름의 파일로 바꾸면 교체됨)
- `public/assets/brand/logo.png` — 학원 로고
- `src/board/` — 3D 보드·말·주사위 (cannon-es 물리: 위로 쓸어 올려 던지기)

## 2단계 결과물
- `data/questions/01.json` ~ `12.json` — 문제 은행 (유형별 40문제 이상)
- `data/config.json` — 칸 보상·채점 설정 (코드 수정 없이 변경)
- `quiz-lab.html` — 퀴즈 연습장 (한 칸 = 5문제 엔진)
- `review.html` — 원장님용 문제 검수 페이지
- `docs/` — 교재 정리, 기존 게임 분석, 샘플 문제
- `legacy/` — 예전 앱 (Step Up 4 Movie Quiz) 원본 보관

## 명령어
```bash
npm install
npm run dev        # 개발 서버
npm test           # 채점 테스트 + 문제 은행 자기검사
npm run validate   # 문제 은행 형식 검사
npm run build      # 검사 후 dist/ 로 빌드
```

## 진행 규칙 (1차 수정)
- 게이트는 건너뛸 수 없다: 10칸 사격장 → 20칸 청크런 → 30칸 카트 → 39칸 크레인. 주사위 눈이 커도 게이트에서 멈추고, 미니게임을 한 판 해야 지나간다. 마지막 마을의 🎮 칸(33·37)은 정답률 70% 이상이면 사격장·카트를 한 판 더.
- 게이트 앞 「관문 시험」: 그 지역에서 서로 다른 시험 유형을 2가지 이상 풀지 않았다면 남은 유형을 풀고 간다. 문장의 성도 도착 전에 같은 확인.
- 완주 화면: 코인이 많을수록 높은 등급(🌱→🥉→🥈→🥇→👑)과 이 기기 순위표.
- 난이도 코스 3단계: **하**(1·2단계, 쉬운 것부터) / **중**(1·2·3단계 고루) / **상**(3단계만). 카트 퀴즈도 같은 난이도를 따른다. 문제 은행 1,098문제 (1단계 264 · 2단계 403 · 3단계 431).
- 마을 클리어 쇼: 1마을 원정대 다 같이 → 2마을 선생님 댄스 → 3마을 피라미드 퍼레이드 → 성 도착 피날레.
- 총점(완주 순위): 코인 × 10 + 빠른 도착 보너스 (25턴 기준, 주사위를 1번 덜 던질 때마다 +30점).
- 음성: 이지·야르는 선생님 녹음 (`public/assets/voice/`), LEGEND는 기기 영어 음성.
- 문제 제한시간: `data/config.json` → `timeLimit.byRegion` (기본 15·15·20·25초), 두 단계 문제는 `byType` (짝꿍 20초, 번역의 탑 40초).
- 미니게임은 판마다 약 3~4분 (크레인 6라운드, 사격장 12라운드, 청크런 미션 6개+보스, 카트 42,000m).
- 개념 학습(`src/study/`): 새 게임을 시작하면 "게임 하기 전에 먼저 학습할까요?"를 묻는다. 4챕터(8품사 → 5품사 청크 → 문장 성분 5개의 의자 → 관사·기타)를 한 장씩 넘기며 보고, 챕터마다 OX 퀴즈 3개. 맞힌 개수만큼 코인. 처음 화면·메뉴·연습장에서 다시 볼 수 있다.
- 순위표(`src/rank/`): 미니게임이 끝날 때마다 점수 기록 + 순위(🥇🥈🥉, 학생별 최고 점수 · 누적 점수 · 판 수). 완주하면 코인 순위. `data/config.json`의 `rankApi`가 비어 있으면 기기별, 구글 Apps Script 주소를 넣으면 반 전체 공유 (`apps-script/README.md`).
