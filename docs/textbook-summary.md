## Chapter 1 품사

### 1-1. 8품사 — 영어 단어의 여덟 가지 무리

**뼈대 4품사 (문장의 몸통)**
| 품사 | 하는 일 | 예 |
|---|---|---|
| 명사 noun | 사람·사물·생각의 이름 | Tom, apple, love |
| 동사 verb | 동작·상태 (~하다, ~이다) | run, eat, is |
| 형용사 adjective | 명사를 꾸미거나 설명 | tall, happy, red |
| 부사 adverb | 동사·형용사·문장을 꾸밈 | quickly, very, always |

**도우미 4품사 (뼈대를 돕는 작은 무리)**
| 품사 | 하는 일 | 예 |
|---|---|---|
| 대명사 pronoun | 명사를 대신하는 말 → 명사 자리에 | I, she, it, them |
| 전치사 preposition | 명사 앞에서 위치·시간·방향 → ( ) / < > 구 | in, on, at, for |
| 접속사 conjunction | 말과 말을 연결 | and, but, because |
| 감탄사 interjection | 감정을 표현 | wow, oops, ouch |

- 명사·형용사·동사·부사 = 사전 단어의 99% 이상 (옥스퍼드 약 17만 개 기준). 나머지 4품사는 다 합쳐도 수백 개뿐.
- 두 품사로 쓰이는 단어가 있다 (run, fast, light …).
- ★ **관사 a, an, the 는 8품사에서 형용사로 본다.**

**연습 ①-A 단어 → 품사** (한 글자 표기: 명·대·동·형·부·전·접·감)
quickly 부 / for 전 / delicious 형 / brave 형 / beautiful 형 / eat 동 / us 대 / beside 전 / she 대 / wow 감 / between 전 / reply 동 / run 동 / slowly 부 / fortunately 부 / in addition to 전 / happiness 명 / amazing 형 / because of 전 / however **부** / under 전 / swim 동 / phew 감 / although 접 / but 접 / excitement 명 / write 동 / friendship 명 / intelligent 형 / because 접 / strength 명 / unless 접 / them 대 / ouch 감 / oops 감 / through 전
> 주의: **however = 부사**, because of = 전치사(구), because = 접속사. 문제 은행에서 함정으로 활용.

**연습 ①-B 한 단어, 여러 품사** — "품사는 생김새가 아니라 하는 일로 정해진다!"
| 단어 | a | b |
|---|---|---|
| run | I **run** every morning. 동사 | He hit a home **run**. 명사 |
| hard | She works **hard**. 부사 | This is a **hard** question. 형용사 |
| help | Can you **help** me? 동사 | Thanks for your **help**. 명사 |
| fast | It is a **fast** car. 형용사 | He runs **fast**. 부사 |
| water | I **water** the plants. 동사 | I drink **water**. 명사 |
| light | The **light** is too bright. 명사 | This box is **light**. 형용사 |
| that | Look at **that** dog. 형용사 | **That** is my dog. 대명사 |
| after | I went home **after** school. 전치사 | … **after** I finished my work. 접속사 |
| well | She sings **well**. 부사 | **Well**, I don't know. 감탄사 |

**연습 ①-C 문장 속 8품사** (예: Wow / she / sings / very / beautifully / on / the / stage = 감 대 동 부 부 전 형 명)
- ※ this soup처럼 명사 앞에서 꾸미면 형용사, This is ~처럼 혼자 쓰이면 대명사.

**연습 ①-D 꼬리(접미사)로 품사 알기**
- 명사 꼬리: -ness -ment -tion -ship -ty
- 형용사 꼬리: -ful -ous -ive -al -y
- 부사 꼬리: 형용사 + -ly (quick → quickly)
- 동사 꼬리: -ize -fy en- (real → realize)

| 명사 | 동사 | 형용사 | 부사 |
|---|---|---|---|
| success | succeed | successful | successfully |
| happiness | — | happy | happily |
| beauty | beautify | beautiful | beautifully |
| care | care | careful | carefully |
| danger | endanger | dangerous | dangerously |
| creation | create | creative | creatively |

### 1-2. 명·동·형·부 — 문장의 뼈대는 네 가지
- 형용사는 명사를 꾸미고, 부사는 동사를 꾸민다 (화살표 도식).
- 도우미: 대명사 → 명사 자리에 / 전치사 → ( ) < > 구 / △접속사 → and, but / 감탄사 → wow, oops
- 대표 예문: **(The cute) ○puppy <quietly> □sleeps <on the sofa>.** = (귀여운) 강아지가 <조용히> 잔다 <소파 위에서>.

### 1-3. 단어 → 구 → 절 : 품사는 "덩어리"에도 붙는다

| | 단어 | 구 | 절 | |
|---|---|---|---|---|
| 명사 ○ (틀: I know ___.) | Jane | her phone number | that she likes me | → 모두 명사 |
| 형용사 ( ) (틀: the book ___) | the (new) book | the book (on the desk) | the book (which I bought) | → 모두 형용사 *(관계대명사절 · 나중에 배워요!)* |
| 부사 < > (틀: He came home ___.) | <late> | <after dinner> | <because he was sick> | → 모두 부사 |

Quick Check: quickly 단어 / in the park 구 / because it rained 절 / to eat lunch 구 / that I like you 절 / playing games 구 / after school 구 / when I was young 절

### 1-4. 구(phrase)의 품사 — 같은 모양, 다른 역할
- **전치사 + 명사 = 전명구.** 형용사구일까, 부사구일까?
  - The book **(on the desk)** is mine. → 명사 book을 꾸밈 → 형용사구 ( )
  - I put the book **<on the desk>**. → 동사 put을 꾸밈 → 부사구 < >
- **판별 비법:** 꾸미는 말이 **명사** → ( 형용사구 ) / 꾸미는 말이 **동사·형용사·문장** → < 부사구 >
- **to부정사구·동명사구도 품사 옷을 입는다**
  - 명사 ○ (~하는 것): To swim in the sea is fun. / Swimming in the sea is fun.
  - 형용사 ( ) (~할): I need some water (to drink).
  - 부사 < > (~하려고, ~하기 위해): I went to the store <to buy milk>.
- ★ 덩어리가 길어져도 하는 일은 똑같다 — 명사 자리면 명사, 꾸미면 형용사·부사!

**연습 ②-A 밑줄 친 구의 품사** — 형·부는 꾸밈받는 말도 함께 쓴다. 예: The girl in the yellow dress … 형 (girl) / lives in Busan 부 (lives) / Playing the guitar 명 / to drink cold water 명 / water to drink 형 (water) / to borrow a book 부 (went) …

### 1-5(연습 ②-B · ③). 청크 표시 방식 ★ 게임 채점 기준

> **원장님 결정 (2026-11-02): 「5품사 청크 독해 법칙」**
> 품사 공부(단어 하나하나)와 청크 독해(덩어리)는 구분한다.
> - **품사 공부 (유형 1~3)**: 단어를 따로따로 본다. the, my, pretty 각각 형용사.
> - **청크 독해 (유형 6~12)**: **명사 앞에 있는 형용사(관사·소유격 포함)는 명사의 일부**로 보고, 통째로 **○ 명사구**로 묶는다.
>   - ○The pretty girl (in the red clothes) ← (The pretty) ○girl 처럼 잘게 자르는 것은 5품사 청크 독해가 아니다.
> - 청크 유형을 시작할 때 이 법칙을 짧게 안내한다:
>   「5품사 청크 독해 법칙 — 명사 앞에 있는 형용사는 명사의 일부! 통째로 명사구 ○로 묶어요.」
>
> 아래 1번은 교재 정답지 표기((The tall) ○girl)와 다르지만, **게임에서는 원장님 결정을 따른다.**

교재 정답지에서 확인한 표시 규칙 + 원장님 결정 (유형 6~12 채점에 적용):

1. **명사 앞 꾸밈말(관사·소유격·형용사)은 명사와 한 덩어리 ○ 명사구** — ○The tall girl, ○My grandfather, ○the museum
   - 명사를 꾸미는 명사도 마찬가지: ○mobile games, ○the cafeteria line
2. **명사 뒤 전명구는 ( ) 형용사구** (뒤에서 꾸미는 말은 따로) — ○girl (in the blue jacket), ○key (to the front door)
3. **대명사는 ○ 명사로 표시** — ○We, ○She, ○I, ○it (5품사 체계에서 대명사는 명사 무리)
4. **동사 덩어리는 한 □** — □is sleeping, □can be (조동사·진행형 포함)
5. **보어 자리 형용사도 ( )** — □smell <really> (sweet). / □was (tired) / □is <really> (exciting)
   - 형용사를 꾸미는 부사는 따로 < > : <really>, <very>
6. **목적어·주어 자리의 to부정사구·동명사구·that절은 통째로 ○** — ○to become a famous singer, ○Reading comic books, ○that English is fun
7. **부사절은 접속사까지 통째로 < >** — <When it snows>, <because it rained heavily>, <because they are fun>
8. **△는 등위접속사(and, but)만 따로 표시** — ○Tom △and ○I / △but
9. **장소·시간 부사는 각각 따로** — <in the park> <every morning>, <at noon> <on weekends>
10. **직독직해는 덩어리 순서대로**: 아기가 / 운다 / 크게 / 한밤중에

### 연습 ④. 거꾸로! 4품사로 영작하기 (유형 11·12의 근거)

| STEP 1 뼈대 찾기 | STEP 2 꾸밈말 찾기 | STEP 3 영어 순서로 | STEP 4 꾸밈말 자리 |
|---|---|---|---|
| 주어 ○ · 동사 □ (목적어가 있으면 ○) | 명사를 꾸미면 ( ) / 동사를 꾸미면 < > | 주어 → 동사 → 목적어 → <어디서> → <언제> | 짧은 ( )는 명사 앞, 긴 ( )는 뒤 / < >는 맨 뒤 (빈도부사는 동사 앞) |

시범: 키 큰 내 친구는 방과 후에 도서관에서 재미있는 책을 읽는다.
→ (My tall) ○friend □reads (an interesting) ○book <in the library> <after school>.

한국어 표시 예: (키 큰) (내) ○친구는 <방과 후에> <도서관에서> (재미있는) ○책을 □읽는다.
→ **한글 문장은 어절(띄어쓰기) 단위로 덩어리를 짓고, 조사는 명사에 붙여 둔다.** (유형 6·8·12 기준)

### 1-5. 관사 a / an / the — 작지만 꼭 챙겨야 할 형용사
- 관사는 형용사! 명사 앞에서 명사를 꾸며 주는 가장 작은 꾸밈말 → (a) book, (the) book
- 서답형에서 in the room = 3단어! 관사를 빼먹으면 단어 수가 안 맞는다.

| a / an = "하나의, 어떤" | the = "그" (누구나 아는 바로 그것) |
|---|---|
| 처음 말하는 셀 수 있는 단수 명사 앞 | 앞에서 말한 것: I have a dog. The dog is cute. |
| 첫 **소리**가 모음이면 an: an apple, an hour, an MP3 | 서로 아는 것: Close the door. Turn off the light. |
| 첫 소리가 자음이면 a: a university, a uniform | 세상에 하나뿐: the sun, the moon, the world |
| 형용사가 붙으면 형용사 소리로: an old car, a big apple | first · best · only · same 앞: the first, the best |

**the를 쓴다 ✔ vs 아무것도 안 쓴다 ✘ (시험에 자주 나오는 짝)**
| 구분 | the | 무관사 (X) | 한 줄 이유 |
|---|---|---|---|
| play + ? | play the piano / the guitar (악기) | play soccer / baseball (운동) | 운동 = "경기 종류" 자체 / 악기 = "그 악기"라는 물건 |
| 장소 | in the room, in the park, at the station | at home, go to school / bed / church | school·bed·church는 건물이 아니라 "본래 목적"(공부·잠·예배) |
| 시간 | in the morning / afternoon / evening | at night, at noon, on Sunday | 하루를 나눈 "그" 시간대 vs 콕 찍는 "때"(굳어진 표현) |
| 식사·교통 | take the bus, The dinner was great. | have breakfast / lunch, by bus / car | 식사 = 매일 하는 "일과" 이름 / by bus = "수단"만 |
| 과목·언어 | the English book (명사를 꾸밀 때) | study math, speak English | 셀 수 없는 "분야 이름" |

★ 실수 주의
- my the book (X) → my book / the book — 소유격·this·that과 관사는 함께 못 쓴다.
- a water, an information (X) — a / an은 셀 수 있는 단수에만!
- a very tall boy — 관사는 형용사보다 맨 앞에. an old car (old의 첫 소리 o)
- go to school (공부하러) vs go to the school (그 학교 건물에, 방문하러)

## Chapter 2 문장 성분

### 2-1. 문장 성분 — 품사가 앉는 "자리"
- **품사 = 단어의 "신분"**, **문장 성분 = 문장 속 "자리(역할)"** — 반장(신분)이 오늘은 발표자(역할)가 될 수도, 청중이 될 수도 있는 것처럼!
- 문장 성분은 **"자리(의자)"**, 품사는 그 의자에 앉는 **"사람"**.

| 의자 | 이름 | 앉는 품사 |
|---|---|---|
| S | 주어 | 명사 (대명사·명사구·명사절) |
| V | **서술어** | 동사 |
| O | 목적어 | 명사 (대명사·명사구·명사절) |
| C | 보어 | 명사 · 형용사 |
| M | 수식어 = **리본** (빼도 되는 장식) | 형용사·부사 무리 |

- 의자(S·V·O·C) = 꼭 필요한 뼈대 / 리본(M 수식어) = 빼도 되는 장식
- 작은 리본(의자 왼쪽) = 짧은 꾸밈말 → 앞에: (the cute) puppy, She <always> plays. ← 빈도부사
- 큰 리본(의자 오른쪽) = 긴 꾸밈말 → 뒤에: the puppy (on the sofa), She plays <in the park>.
- <부사>는 보통 문장 맨 뒤로! (목적어·보어 뒤)
- 품사마다 앉는 의자가 정해져 있다: 명사 → S·O·C 의자 / 동사 → V 의자 / 형용사 → C 의자. 자리를 바꿔 앉을 수 없다!
  - 예: Music(명사·S) makes(동사·V) me(대명사·O) happy(형용사·C).

> ⚠ 게임 표기 (원장님 결정): 교재 용어 **"서술어"** 를 쓰되, 최근 어법책이 서술어 자리를 "동사"로 부르는 것에 맞춰 **"서술어(동사)"** 로 함께 적는다.
> 유형 5 선택지: `주어(S) / 서술어(동사)(V) / 목적어(O) / 보어(C) / 수식어(M)`. 서술어 자리에 앉는 품사는 동사뿐이기 때문.

### 2-2. 같은 단어 다른 자리 · 보어 vs 목적어 · 성분 찾기
- 같은 명사 music이 앉는 의자에 따라 주어(S) → 목적어(O) → 보어(C)로 바뀐다.
- **보어 vs 목적어 — 헷갈리면 "=" 를 넣어 보자**
  - 보어 C: 주어 = 보어 (She = a doctor) / She is happy. (O) She is happily. (X) → **보어 자리엔 명사·형용사만! 부사는 못 앉아요.**
  - 목적어 O: 주어 ≠ 목적어 (She ≠ a doctor, 누구를?) → **목적어 자리엔 명사·대명사(구·절)!**
- **성분 찾기 4단계 — 동사부터 찾아라!**
  1. 동사(V) 찾기 — 문장의 심장부터!
  2. 동사 앞 = 주어(S) — 누가 / 무엇이?
  3. 동사 뒤 = O 또는 C — 누구를·무엇을? → O / 주어 설명 → C
  4. 나머지 = 수식어(M) — ( ) < > 로 묶기
  - 예: <Yesterday> (my) ○brother (in Seoul) □called ○me <at midnight>. → 뼈대: brother called me

> 교재 PDF에 2-3절·연습 ⑥은 없음 (2-2 다음이 2-4, ⑤ 다음이 ⑦). → 원장님 확인: 없어도 됨.

### 2-4. 뼈대 찾기 · 다섯 가지 뼈대 · 품사와 성분
- **수식어를 걷어내면 뼈대가 보인다!** ~~(My little)~~ brother ~~<always>~~ plays ~~(computer)~~ games ~~<after school>~~ → brother plays games (S+V+O)

| 형식 | 뼈대 | 예문 | 뜻 |
|---|---|---|---|
| 1형식 | S V | Birds sing. | 새들이 노래한다 |
| 2형식 | S V C | She is happy. | 주어 = 보어 |
| 3형식 | S V O | I love music. | ~을/를 |
| 4형식 | S V O O | Mom gave me a gift. | ~에게 ~을 |
| 5형식 | S V O C | The news made me happy. | 목적어 = 보어 |

**품사 → 성분 연결표** (단어든 구든 절이든, 같은 자리에 앉을 수 있다!)
| 자리 | 단어 | 구 | 절 |
|---|---|---|---|
| 주어 S | Soccer is fun. | Playing soccer is fun. | — |
| 목적어 O | I like soccer. | I like playing soccer. | I know that he is honest. |
| 보어 C | He is (happy). | My dream is to be a doctor. | — |
| 수식어 M (형) | the (tall) boy | the boy (in the room) | — |
| 수식어 M (부) | He ran <quickly>. | He ran <in the morning>. | He ran <because he was late>. |

→ 주어·목적어 자리 = **명사 무리** / 보어 자리 = **명사·형용사 무리** / 수식어 자리 = **형용사·부사 무리**

**연습 ⑤ 몇 형식?** The baby smiled 1 / My father is a firefighter 2 / The leaves turned red 2 / I read a book 3 / She bought me a nice watch 4 / We call our dog Coco 5 / The birds sing beautifully 1 / He showed us his new bike 4 / This song makes me happy 5 / My brother plays soccer 3
- 힌트: be동사·become·look·turn 뒤 = 보어(C) → 2형식 / give·buy·show + 사람 + 물건 → 4형식 / make·call + 목적어 + 보어 → 5형식

### 2-5. 형용사? 부사? — 보어(C)일까, 수식어(M)일까
- 앞의 명사(주어)를 설명하면 → 보어(C) 자리 → **형용사** / 앞의 동사를 꾸미면 → 수식어(M) 자리 → **부사**
- "~하게"로 해석돼도 형용사!

| 종류 | 동사 | 예문 |
|---|---|---|
| 감각동사 | look, sound, smell, taste, feel | You look tired. This cake tastes sweet. |
| 상태 유지 | keep, stay, remain | Keep quiet. Stay calm. |
| 상태 변화 | become, get, turn, grow, go(나쁘게), come(come true) | It got dark. The leaves turned red. Milk went bad. |
| 추측 | seem, appear | He seems happy. |

- ★ 5형식도 같은 원리: The news made me happy. Keep the room clean. → 목적어를 설명하니까 형용사!
- 연습: looks sad / walked slowly / smells good / keep quiet / slept peacefully / getting dark / look beautiful / sings beautifully / went bad / Stay calm / answered correctly / made me happy

### 연습 ⑦-A · ⑦-B. 성분 쓰기 / 품사와 성분 함께
- ★ 같은 reading books가 자리만 바뀌어 주어(Reading books is my hobby) → 보어(My hobby is reading books) → 목적어(I like reading books)!
- ⑦-B 정답 표기 형식 (게임 해설에 그대로 사용): `대명사 S` / `명사 C` / `형용사 C` / `동사 V` / `명사(구) O` / `부사(구) M` / `형용사구 M` / `명사절 O` / `명사구 S` / `부사절 M`

### 연습 ⑧. 뼈대 찾기 · 보어와 목적어
- 뼈대 쓰기 형식: `뼈대: sister eats ice cream (S V O)`
- "=" 가 성립하면 보어! 보어 자리엔 형용사, 수식어 자리엔 부사.

**Chapter 2 한 줄 정리:** 문장은 S·V·O·C 뼈대에 M(수식어)이라는 옷을 입힌 것입니다. 뼈대 자리엔 명사·동사·형용사가, 옷(수식어) 자리엔 형용사·부사가 앉습니다. 자리를 알면, 문장이 보입니다.

  - "She = tired, '=' 가 성립 → 보어(C). 보어 자리엔 형용사!"

## 4. 문제 출제 원칙 (원장님 결정, 2026-11-02)
- **예문은 교재 문장을 그대로 쓰지 않는다.** 원리는 교재에서, 문장은 학생이 체감하는 소재(급식·학원·체육대회·게임·친구·하루 일과)로 응용한다.
- **유형 1·2**: 8품사 중 5개를 골라 보기로 낸다 (정답 + 그럴듯한 오답 4개). she → 대명사, however → 부사 같은 교재 함정 활용.
- **접속사 문제는 되도록 내지 않는다.** △ 표시는 청크 구분(유형 8~10)에서만 다룬다.
  - **한글 접속사는 부사절 형태로만** (예: 「비가 와서」 「내가 늦었을 때」 → < 부사절 >).
  - 「그러나」 「그리고」 같은 말은 국어에서 부사이므로 **출제하지 않는다.**
- **유형 12 번역의 탑(난이도 상)**: 한글 덩어리 → 영어 어순으로 다시 배열(STEP 3) → 덩어리마다 영작. 두 단계 모두 학생이 한다.
